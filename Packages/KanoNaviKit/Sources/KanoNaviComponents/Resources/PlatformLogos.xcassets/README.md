# Platform Logos

The YouTube, X and Bilibili logos are custom symbols made from
[Simple Icons](https://github.com/simple-icons/simple-icons) 16.36.0
(`icons/youtube.svg`, `icons/x.svg`, `icons/bilibili.svg`). Simple Icons
releases its SVG data under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md);
the logos themselves are trademarks of their owners and only mark links to
and names of those platforms.

Each `.symbolset` holds one Regular-M glyph: the 24-unit icon box scaled to 88
units at the 100 pt reference size, centered between the baseline and the
cap line.

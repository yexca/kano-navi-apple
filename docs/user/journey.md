# Journey

The **Journey** section (in **More**, or the sidebar) presents Kano Mahoro's public milestones
since 2010 alongside a visual gallery.

## Timeline and Gallery

A segmented control in the toolbar switches between two views, both filtered by a
pinned horizontal row of identity chips (**All** and each activity branch with
its count):

- **Timeline:** Lists milestones oldest first by year, preserving each
  milestone's stored date precision (year, month, or day), highlight marker,
  detail text in your content language, thumbnails, and source links. Tapping a
  milestone opens its full detail page; milestones linked to a release include a
  **View in Works** button.
- **Gallery:** Shows every milestone image and gallery-only image, with an
  image-type filter (artwork, models, merchandise, video frames, covers).

## Image Viewer

Tapping any image opens the full-screen image viewer (or a large sheet on Mac)
with pinch/double-tap zoom, swipe paging, title, date, creator and publisher
credits, source links, and a **Details** sheet for provenance notes.
